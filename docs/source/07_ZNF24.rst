I. IDENTIFY THE ZNF24–nTum-6.4314 GENOMIC ARCHITECTURE
======================================================

The ZNF24 chimeric architecture was identified in
*Myotis daubentonii*.

Two transcript configurations are associated with this locus.

The five-exon transcript contains four host-derived ZNF24 exons followed
by a terminal exon derived from the transposable element nTum-6.4314::

    ZNF24 exon 1
        |
    ZNF24 exon 2
        |
    ZNF24 exon 3
        |
    ZNF24 exon 4
        |
    nTum-6.4314-derived exon

A second transcript contains the same ZNF24 exons 1–3 and the same
nTum-6.4314-derived terminal exon but lacks ZNF24 exon 4::

    ZNF24 exon 1
        |
    ZNF24 exon 2
        |
    ZNF24 exon 3
        |
    nTum-6.4314-derived exon

Because these two transcripts can originate from the same genomic locus,
the comparative genomic analysis searches for the ZNF24–nTum-6.4314
locus rather than attempting to distinguish transcript isoforms.

ZNF24 exons 1–3 therefore constitute the shared host-gene anchor.
ZNF24 exon 4 is analyzed as an additional host-derived exon whose
presence can distinguish the longer genomic configuration, whereas
nTum-6.4314 is analyzed independently as the TE-derived component.

6. Search for the ZNF24–nTum-6.4314 architecture across species
----------------------------------------------------------------

The comparative genomic search uses ZNF24 exons 1–3 as the mandatory
host-gene anchor.

ZNF24 exon 4 is treated as an optional additional host-derived exon
because the two candidate transcripts differ by inclusion or skipping
of this exon.

The nTum-6.4314-derived sequence is searched independently toward the
biological 3′ end of the reconstructed ZNF24 locus.

In the positive *Myotis daubentonii* locus, nTum-6.4314 begins
approximately 14.2 kb downstream of exon 4 and approximately 18.2 kb
downstream of exon 3. A 25-kb search window is therefore used.


Create the general detection script
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create the script::

    nano scripts/02_find_ZNF24_chimeric_signature.py

.. code-block:: python

    #!/usr/bin/env python3
    
    import sys
    import subprocess
    from pathlib import Path
    from collections import defaultdict
    
    
    # ============================================================
    # PARAMETERS
    # ============================================================
    
    MIN_EXON_IDENTITY = 70.0
    MIN_EXON_QCOV = 70.0
    
    MIN_TE_IDENTITY = 70.0
    MIN_TE_QCOV = 70.0
    
    MAX_EXON_GAP = 20000
    MAX_TE_DISTANCE = 25000
    
    
    # ============================================================
    # PATHS
    # ============================================================
    
    SCRIPT = Path(__file__).resolve()
    ROOT = SCRIPT.parent.parent
    PROJECT = ROOT.parent.parent
    
    SPECIES_ROOT = PROJECT / "SPECIES"
    
    EXON_PROBES = ROOT / "sequences" / "ZNF24_host_exon_probes.fa"
    TE_PROBE = ROOT / "sequences" / "ZNF24_nTum-6.4314_probe.fa"
    
    INTERMEDIATE = ROOT / "intermediate"
    RESULTS = ROOT / "results"
    
    
    # ============================================================
    # FUNCTIONS
    # ============================================================
    
    def run(cmd):
        subprocess.run(cmd, check=True)
    
    
    def strand_from_coordinates(sstart, send):
        return "+" if sstart <= send else "-"
    
    
    def interval(sstart, send):
        return min(sstart, send), max(sstart, send)
    
    
    def exon_number(query):
        try:
            return int(
                query.replace("ZNF24_exon", "")
                     .replace("_match", "")
            )
        except Exception:
            return None
    
    
    def read_blast(path):
    
        hits = []
    
        with open(path) as fh:
    
            for line in fh:
    
                if not line.strip():
                    continue
    
                fields = line.rstrip().split("\t")
    
                if len(fields) != 12:
                    continue
    
                (
                    qseqid,
                    sseqid,
                    pident,
                    length,
                    qlen,
                    qstart,
                    qend,
                    sstart,
                    send,
                    evalue,
                    bitscore,
                    qcov
                ) = fields
    
                sstart = int(sstart)
                send = int(send)
    
                start, end = interval(sstart, send)
    
                hits.append({
                    "query": qseqid,
                    "scaffold": sseqid,
                    "identity": float(pident),
                    "length": int(length),
                    "qlen": int(qlen),
                    "qstart": int(qstart),
                    "qend": int(qend),
                    "sstart": sstart,
                    "send": send,
                    "start": start,
                    "end": end,
                    "strand": strand_from_coordinates(sstart, send),
                    "evalue": evalue,
                    "bitscore": float(bitscore),
                    "qcov": float(qcov)
                })
    
        return hits
    
    
    # ============================================================
    # INPUT
    # ============================================================
    
    if len(sys.argv) != 2:
        sys.exit(
            "Usage: python3 scripts/02_find_ZNF24_chimeric_signature.py "
            "<Species_name>"
        )
    
    species = sys.argv[1]
    
    species_dir = SPECIES_ROOT / species
    
    if not species_dir.exists():
        sys.exit(f"Species directory not found: {species_dir}")
    
    
    # ============================================================
    # FIND GENOME
    # ============================================================
    
    genomes = list(species_dir.glob("*.fa"))
    
    if len(genomes) == 0:
        sys.exit(f"No *.fa genome found for {species}")
    
    if len(genomes) > 1:
        sys.exit(
            f"More than one *.fa genome found for {species}: "
            + ", ".join(x.name for x in genomes)
        )
    
    genome = genomes[0]
    
    
    # ============================================================
    # DIRECTORIES
    # ============================================================
    
    species_intermediate = INTERMEDIATE / species
    species_intermediate.mkdir(parents=True, exist_ok=True)
    
    db_dir = INTERMEDIATE / "blast_db" / species
    db_dir.parent.mkdir(parents=True, exist_ok=True)
    
    RESULTS.mkdir(parents=True, exist_ok=True)
    
    db_prefix = str(db_dir)
    
    
    # ============================================================
    # BUILD BLAST DATABASE
    # ============================================================
    
    existing_db_files = list(
        db_dir.parent.glob(db_dir.name + ".*")
    )
    
    if not existing_db_files:
    
        print(f"Building BLAST database for {species}...")
    
        run([
            "makeblastdb",
            "-in", str(genome),
            "-dbtype", "nucl",
            "-out", db_prefix
        ])
    
    else:
    
        print(f"Reusing ZNF24 BLAST database for {species}")
    
    
    # ============================================================
    # BLAST HOST EXONS
    # ============================================================
    
    exon_out = (
        species_intermediate /
        f"ZNF24_exon_matches_{species}.tsv"
    )
    
    run([
        "blastn",
        "-query", str(EXON_PROBES),
        "-db", db_prefix,
        "-task", "blastn",
        "-word_size", "7",
        "-dust", "no",
        "-evalue", "1e-10",
        "-outfmt",
        "6 qseqid sseqid pident length qlen qstart qend "
        "sstart send evalue bitscore qcovhsp",
        "-out", str(exon_out)
    ])
    
    
    # ============================================================
    # BLAST nTum-6.4314
    # ============================================================
    
    te_out = (
        species_intermediate /
        f"ZNF24_nTum_matches_{species}.tsv"
    )
    
    run([
        "blastn",
        "-query", str(TE_PROBE),
        "-db", db_prefix,
        "-task", "blastn",
        "-word_size", "7",
        "-dust", "no",
        "-evalue", "1e-20",
        "-outfmt",
        "6 qseqid sseqid pident length qlen qstart qend "
        "sstart send evalue bitscore qcovhsp",
        "-out", str(te_out)
    ])
    
    
    # ============================================================
    # FILTER HOST EXONS
    # ============================================================
    
    exon_hits = []
    
    for h in read_blast(exon_out):
    
        n = exon_number(h["query"])
    
        if n is None:
            continue
    
        if h["identity"] < MIN_EXON_IDENTITY:
            continue
    
        if h["qcov"] < MIN_EXON_QCOV:
            continue
    
        h["exon"] = n
    
        exon_hits.append(h)
    
    
    # ============================================================
    # FILTER TE HITS
    # ============================================================
    
    te_hits = [
        h for h in read_blast(te_out)
        if h["identity"] >= MIN_TE_IDENTITY
        and h["qcov"] >= MIN_TE_QCOV
    ]
    
    
    # ============================================================
    # GROUP HOST HITS
    # ============================================================
    
    groups = defaultdict(list)
    
    for h in exon_hits:
        groups[(h["scaffold"], h["strand"])].append(h)
    
    
    candidate_loci = []
    
    
    # ============================================================
    # RECONSTRUCT ZNF24 LOCI
    # ============================================================
    
    for (scaffold, strand), hits in groups.items():
    
        hits = sorted(hits, key=lambda x: x["start"])
    
        clusters = []
        current = []
    
        for hit in hits:
    
            if not current:
                current = [hit]
                continue
    
            previous_end = max(x["end"] for x in current)
            gap = hit["start"] - previous_end
    
            if gap <= MAX_EXON_GAP:
                current.append(hit)
    
            else:
                clusters.append(current)
                current = [hit]
    
        if current:
            clusters.append(current)
    
    
        for cluster in clusters:
    
            best_by_exon = {}
    
            for h in cluster:
    
                n = h["exon"]
    
                if (
                    n not in best_by_exon
                    or h["bitscore"] > best_by_exon[n]["bitscore"]
                ):
                    best_by_exon[n] = h
    
    
            # Exons 1, 2 and 3 are mandatory
            if not all(
                n in best_by_exon
                for n in [1, 2, 3]
            ):
                continue
    
    
            selected = [
                best_by_exon[n]
                for n in sorted(best_by_exon)
            ]
    
    
            # ----------------------------------------------------
            # Verify transcriptional order
            # ----------------------------------------------------
    
            positions = [
                (h["start"] + h["end"]) / 2
                for h in selected
            ]
    
            if strand == "+":
    
                ordered = all(
                    positions[i] < positions[i + 1]
                    for i in range(len(positions) - 1)
                )
    
            else:
    
                ordered = all(
                    positions[i] > positions[i + 1]
                    for i in range(len(positions) - 1)
                )
    
    
            if not ordered:
                continue
    
    
            locus_start = min(
                h["start"] for h in selected
            )
    
            locus_end = max(
                h["end"] for h in selected
            )
    
    
            # ----------------------------------------------------
            # Exon 4 is optional
            # ----------------------------------------------------
    
            exon4_present = 4 in best_by_exon
    
            if exon4_present:
                terminal_exon = best_by_exon[4]
            else:
                terminal_exon = best_by_exon[3]
    
    
            # ----------------------------------------------------
            # Biological 3' end
            # ----------------------------------------------------
    
            if strand == "+":
                three_prime = terminal_exon["end"]
            else:
                three_prime = terminal_exon["start"]
    
    
            # ----------------------------------------------------
            # Search nTum-6.4314 toward biological 3'
            # ----------------------------------------------------
    
            nearby_te = []
    
            for te in te_hits:
    
                if te["scaffold"] != scaffold:
                    continue
    
                if te["strand"] != strand:
                    continue
    
    
                if strand == "+":
    
                    distance = te["start"] - three_prime
    
                    if 0 <= distance <= MAX_TE_DISTANCE:
                        nearby_te.append(
                            (distance, te)
                        )
    
                else:
    
                    distance = three_prime - te["end"]
    
                    if 0 <= distance <= MAX_TE_DISTANCE:
                        nearby_te.append(
                            (distance, te)
                        )
    
    
            nearby_te.sort(
                key=lambda x: (
                    x[0],
                    -x[1]["bitscore"]
                )
            )
    
    
            # ----------------------------------------------------
            # CLASSIFY
            # ----------------------------------------------------
    
            exons_found = sorted(best_by_exon)
    
    
            if nearby_te:
    
                distance, te = nearby_te[0]
    
                if exon4_present:
                    status = "ZNF24_NTUM_WITH_EXON4"
                else:
                    status = "ZNF24_NTUM_NO_EXON4"
    
                te_start = te["start"]
                te_end = te["end"]
                te_identity = te["identity"]
                te_qcov = te["qcov"]
    
            else:
    
                status = "ZNF24_LIKE_NO_3PRIME_NTUM"
    
                distance = ""
                te_start = ""
                te_end = ""
                te_identity = ""
                te_qcov = ""
    
    
            candidate_loci.append({
    
                "species": species,
                "genome": genome.name,
                "scaffold": scaffold,
                "strand": strand,
    
                "locus_start": locus_start,
                "locus_end": locus_end,
    
                "exons": ",".join(
                    map(str, exons_found)
                ),
    
                "exon4_present":
                    "YES" if exon4_present else "NO",
    
                "three_prime": three_prime,
    
                "te_start": te_start,
                "te_end": te_end,
    
                "te_identity": te_identity,
                "te_qcov": te_qcov,
    
                "te_distance": distance,
    
                "status": status
            })
    
    
    # ============================================================
    # WRITE RESULTS
    # ============================================================
    
    result_file = (
        RESULTS /
        f"ZNF24_signature_{species}.tsv"
    )
    
    header = [
    
        "Species",
        "Genome",
        "Scaffold",
        "Strand",
    
        "ZNF24_start",
        "ZNF24_end",
    
        "Exons_found",
        "Exon4_present",
    
        "Biological_3prime",
    
        "nTum_start",
        "nTum_end",
    
        "nTum_identity",
        "nTum_qcov",
    
        "nTum_distance_3prime",
    
        "Status"
    ]
    
    
    with open(result_file, "w") as out:
    
        out.write(
            "\t".join(header) + "\n"
        )
    
        for x in sorted(
            candidate_loci,
            key=lambda z: (
                z["scaffold"],
                z["locus_start"]
            )
        ):
    
            row = [
    
                x["species"],
                x["genome"],

~~~~~~~~~~~~~~~
    
Create the log directory

Because zsh can complain when a wildcard matches no files, remove old

        find results/batch_logs -type f \

Run three species simultaneously
