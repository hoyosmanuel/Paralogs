6. Lo lanzamos para todos
-----------------------------

.. code-block:: bash

   nano scripts/02_find_ZFP28_chimeric_signature.py

.. code-block:: bash

   #!/usr/bin/env python3
   
   import sys
   import subprocess
   from pathlib import Path
   from collections import defaultdict
   
   
   # ============================================================
   # PARAMETERS
   # ============================================================
   
   MIN_EXON_IDENTITY = 70.0
   MIN_EXON_QCOV = 70.0
   
   MIN_TE_IDENTITY = 70.0
   MIN_TE_QCOV = 70.0
   
   MIN_EXONS_PER_LOCUS = 4
   
   # Maximum gap between neighboring ZFP28 exon hits
   MAX_EXON_GAP = 20000
   
   # Positive controls:
   # Eonycteris spelaea     = 18,602 bp
   # Rousettus aegyptiacus = 18,814 bp
   MAX_TE_DISTANCE = 25000
   
   
   # ============================================================
   # PATHS
   # ============================================================
   
   SCRIPT = Path(__file__).resolve()
   ROOT = SCRIPT.parent.parent
   PROJECT = ROOT.parent.parent
   
   SPECIES_ROOT = PROJECT / "SPECIES"
   
   EXON_PROBES = ROOT / "sequences" / "ZFP28_host_exon_probes.fa"
   TE_PROBE = ROOT / "sequences" / "ZFP28_GOLEM-1p_probe.fa"
   
   INTERMEDIATE = ROOT / "intermediate"
   RESULTS = ROOT / "results"
   
   
   # ============================================================
   # FUNCTIONS
   # ============================================================
   
   def run(cmd):
       subprocess.run(cmd, check=True)
   
   
   def strand_from_coordinates(sstart, send):
       return "+" if sstart <= send else "-"
   
   
   def exon_number(query):
       try:
           return int(
               query.replace("ZFP28_exon", "")
                    .replace("_match", "")
           )
       except Exception:
           return None
   
   
   def read_blast(path):
   
       hits = []
   
       with open(path) as fh:
   
           for line in fh:
   
               if not line.strip():
                   continue
   
               fields = line.rstrip().split("\t")
   
               if len(fields) != 12:
                   continue
   
               (
                   qseqid,
                   sseqid,
                   pident,
                   length,
                   qlen,
                   qstart,
                   qend,
                   sstart,
                   send,
                   evalue,
                   bitscore,
                   qcov
               ) = fields
   
               sstart = int(sstart)
               send = int(send)
   
               hits.append({
                   "query": qseqid,
                   "scaffold": sseqid,
                   "identity": float(pident),
                   "length": int(length),
                   "qlen": int(qlen),
                   "qstart": int(qstart),
                   "qend": int(qend),
                   "sstart": sstart,
                   "send": send,
                   "start": min(sstart, send),
                   "end": max(sstart, send),
                   "strand": strand_from_coordinates(sstart, send),
                   "evalue": evalue,
                   "bitscore": float(bitscore),
                   "qcov": float(qcov)
               })
   
       return hits
   
   
   # ============================================================
   # INPUT
   # ============================================================
   
   if len(sys.argv) != 2:
       sys.exit(
           "Usage: python3 scripts/02_find_ZFP28_chimeric_signature.py "
           "<Species_name>"
       )
   
   species = sys.argv[1]
   
   species_dir = SPECIES_ROOT / species
   
   if not species_dir.exists():
       sys.exit(f"Species directory not found: {species_dir}")
   
   
   # ============================================================
   # FIND GENOME
   # ============================================================
   
   genomes = list(species_dir.glob("*.fa"))
   
   if len(genomes) == 0:
       sys.exit(f"No *.fa genome found for {species}")
   
   if len(genomes) > 1:
       sys.exit(
           f"More than one *.fa genome found for {species}: "
           + ", ".join(x.name for x in genomes)
       )
   
   genome = genomes[0]
   
   
   # ============================================================
   # DIRECTORIES
   # ============================================================
   
   species_intermediate = INTERMEDIATE / species
   species_intermediate.mkdir(parents=True, exist_ok=True)
   
   db_dir = INTERMEDIATE / "blast_db" / species
   db_dir.parent.mkdir(parents=True, exist_ok=True)
   
   RESULTS.mkdir(parents=True, exist_ok=True)
   
   db_prefix = str(db_dir)
   
   
   # ============================================================
   # BUILD BLAST DATABASE
   # ============================================================
   
   existing_db_files = list(
       db_dir.parent.glob(db_dir.name + ".*")
   )
   
   if not existing_db_files:
   
       print(f"Building BLAST database for {species}...")
   
       run([
           "makeblastdb",
           "-in", str(genome),
           "-dbtype", "nucl",
           "-out", db_prefix
       ])
   
   else:
   
       print(f"Reusing ZFP28 BLAST database for {species}")
   
   
   # ============================================================
   # BLAST HOST EXONS
   # ============================================================
   
   exon_out = (
       species_intermediate /
       f"ZFP28_exon_matches_{species}.tsv"
   )
   
   run([
       "blastn",
       "-query", str(EXON_PROBES),
       "-db", db_prefix,
       "-task", "blastn",
       "-word_size", "7",
       "-dust", "no",
       "-evalue", "1e-10",
       "-outfmt",
       "6 qseqid sseqid pident length qlen qstart qend "
       "sstart send evalue bitscore qcovhsp",
       "-out", str(exon_out)
   ])
   
   
   # ============================================================
   # BLAST GOLEM-1p
   # ============================================================
   
   te_out = (
       species_intermediate /
       f"ZFP28_GOLEM_matches_{species}.tsv"
   )
   
   run([
       "blastn",
       "-query", str(TE_PROBE),
       "-db", db_prefix,
       "-task", "blastn",
       "-word_size", "7",
       "-dust", "no",
       "-evalue", "1e-20",
       "-outfmt",
       "6 qseqid sseqid pident length qlen qstart qend "
       "sstart send evalue bitscore qcovhsp",
       "-out", str(te_out)
   ])
   
   
   # ============================================================
   # FILTER EXON HITS
   # ============================================================
   
   exon_hits = []
   
   for h in read_blast(exon_out):
   
       n = exon_number(h["query"])
   
       if n is None:
           continue
   
       if h["identity"] < MIN_EXON_IDENTITY:
           continue
   
       if h["qcov"] < MIN_EXON_QCOV:
           continue
   
       h["exon"] = n
       exon_hits.append(h)
   
   
   # ============================================================
   # FILTER GOLEM HITS
   # ============================================================
   
   te_hits = [
       h for h in read_blast(te_out)
       if h["identity"] >= MIN_TE_IDENTITY
       and h["qcov"] >= MIN_TE_QCOV
   ]
   
   
   # ============================================================
   # GROUP HOST HITS BY SCAFFOLD AND STRAND
   # ============================================================
   
   groups = defaultdict(list)
   
   for h in exon_hits:
       groups[(h["scaffold"], h["strand"])].append(h)
   
   
   candidate_loci = []
   
   
   # ============================================================
   # RECONSTRUCT ZFP28-LIKE LOCI
   # ============================================================
   
   for (scaffold, strand), hits in groups.items():
   
       hits = sorted(hits, key=lambda x: x["start"])
   
       clusters = []
       current = []
   
       for hit in hits:
   
           if not current:
               current = [hit]
               continue
   
           previous_end = max(x["end"] for x in current)
   
           gap = hit["start"] - previous_end
   
           if gap <= MAX_EXON_GAP:
               current.append(hit)
   
           else:
               clusters.append(current)
               current = [hit]
   
       if current:
           clusters.append(current)
   
   
       # ========================================================
       # EVALUATE EACH CLUSTER
       # ========================================================
   
       for cluster in clusters:
   
           best_by_exon = {}
   
           for h in cluster:
   
               n = h["exon"]
   
               if (
                   n not in best_by_exon
                   or h["bitscore"] > best_by_exon[n]["bitscore"]
               ):
                   best_by_exon[n] = h
   
   
           exons_found = sorted(best_by_exon)
   
           if len(exons_found) < MIN_EXONS_PER_LOCUS:
               continue
   
           # Exon 6 anchors the biological 3' end
           if 6 not in best_by_exon:
               continue
   
   
           selected = [
               best_by_exon[n]
               for n in exons_found
           ]
   
   
           # ----------------------------------------------------
           # Verify transcriptional exon order
           # ----------------------------------------------------
   
           positions = [
               (h["start"] + h["end"]) / 2
               for h in selected
           ]
   
           if strand == "+":
   
               ordered = all(
                   positions[i] < positions[i + 1]
                   for i in range(len(positions) - 1)
               )
   
           else:
   
               ordered = all(
                   positions[i] > positions[i + 1]
                   for i in range(len(positions) - 1)
               )
   
           if not ordered:
               continue
   
   
           locus_start = min(
               h["start"] for h in selected
           )
   
           locus_end = max(
               h["end"] for h in selected
           )
   
   
           # ----------------------------------------------------
           # Biological 3' end = exon 6
           # ----------------------------------------------------
   
           exon6 = best_by_exon[6]
   
           if strand == "+":
               three_prime = exon6["end"]
           else:
               three_prime = exon6["start"]
   
   
           # ----------------------------------------------------
           # Find GOLEM toward biological 3'
           # ----------------------------------------------------
   
           nearby_te = []
   
           for te in te_hits:
   
               if te["scaffold"] != scaffold:
                   continue
   
               if te["strand"] != strand:
                   continue
   
   
               if strand == "+":
   
                   distance = te["start"] - three_prime
   
                   if 0 <= distance <= MAX_TE_DISTANCE:
                       nearby_te.append(
                           (distance, te)
                       )
   
               else:
   
                   distance = three_prime - te["end"]
   
                   if 0 <= distance <= MAX_TE_DISTANCE:
                       nearby_te.append(
                           (distance, te)
                       )
   
   
           nearby_te.sort(
               key=lambda x: (
                   x[0],
                   -x[1]["bitscore"]
               )
           )
   
   
           # ----------------------------------------------------
           # CLASSIFY
           # ----------------------------------------------------
   
           if nearby_te:
   
               distance, te = nearby_te[0]
   
               if exons_found == [1, 2, 3, 4, 5, 6]:
                   status = "ZFP28_CHIMERIC_COMPLETE"
               else:
                   status = "ZFP28_CHIMERIC_PARTIAL"
   
               te_start = te["start"]
               te_end = te["end"]
               te_identity = te["identity"]
               te_qcov = te["qcov"]
   
           else:
   
               status = "ZFP28_LIKE_NO_3PRIME_GOLEM"
   
               distance = ""
               te_start = ""
               te_end = ""
               te_identity = ""
               te_qcov = ""
   
   
           candidate_loci.append({
   
               "species": species,
               "genome": genome.name,
               "scaffold": scaffold,
               "strand": strand,
   
               "locus_start": locus_start,
               "locus_end": locus_end,
   
               "exons": ",".join(
                   map(str, exons_found)
               ),
   
               "n_exons": len(exons_found),
   
               "three_prime": three_prime,
   
               "te_start": te_start,
               "te_end": te_end,
   
               "te_identity": te_identity,
               "te_qcov": te_qcov,
   
               "te_distance": distance,
   
               "status": status
           })
   
   
   # ============================================================
   # WRITE RESULTS
   # ============================================================
   
   result_file = (
       RESULTS /
       f"ZFP28_signature_{species}.tsv"
   )
   
   header = [
   
       "Species",
       "Genome",
       "Scaffold",
       "Strand",
   
       "ZFP28_start",
       "ZFP28_end",
   
       "Exons_found",
       "Number_of_exons",
   
       "Biological_3prime",
   
       "GOLEM_start",
       "GOLEM_end",
   
       "GOLEM_identity",
       "GOLEM_qcov",
   
       "GOLEM_distance_3prime",
   
       "Status"
   ]
   
   
   with open(result_file, "w") as out:
   
       out.write("\t".join(header) + "\n")
   
       for x in sorted(
           candidate_loci,
           key=lambda z: (
               z["scaffold"],
               z["locus_start"]
           )
       ):
   
           row = [
   
               x["species"],
               x["genome"],
               x["scaffold"],
               x["strand"],
   
               x["locus_start"],
               x["locus_end"],
   
               x["exons"],
               x["n_exons"],
   
               x["three_prime"],
   
               x["te_start"],
               x["te_end"],
   
               x["te_identity"],
               x["te_qcov"],
   
               x["te_distance"],
   
               x["status"]
           ]
   
           out.write(
               "\t".join(map(str, row)) + "\n"
           )
   
   
   # ============================================================
   # HUMAN-READABLE SUMMARY
   # ============================================================
   
   print()
   print("=" * 72)
   print(f"ZFP28 analysis: {species}")
   print("=" * 72)
   
   
   if not candidate_loci:
   
       print("No coherent ZFP28-like locus detected.")
   
   else:
   
       for x in candidate_loci:
   
           print()
   
           print(
               f"{x['scaffold']}  "
               f"{x['locus_start']}-{x['locus_end']}  "
               f"strand {x['strand']}"
           )
   
           print(
               f"Exons: {x['exons']} "
               f"({x['n_exons']} exons)"
           )
   
           if x["status"].startswith("ZFP28_CHIMERIC"):
   
               print(
                   f"GOLEM-1p: "
                   f"{x['te_start']}-{x['te_end']}"
               )
   
               print(
                   f"Identity: "
                   f"{x['te_identity']:.3f}%"
               )
   
               print(
                   f"Coverage: "
                   f"{x['te_qcov']:.1f}%"
               )
   
               print(
                   f"3' distance: "
                   f"{x['te_distance']} bp"
               )
   
           print(f"-> {x['status']}")
   
   
   print()
   print(f"Results: {result_file}")

8. Validación del sitio aceptor de splicing del exón 7
------------------------------------------------------

Después de identificar los loci candidatos completos de ZFP28–GOLEM-1p,
se realizó una validación adicional del límite 5′ del exón 7 derivado
del elemento transponible.

El objetivo fue determinar si la secuencia inmediatamente anterior al
exón 7 conservaba el dinucleótido aceptor canónico ``AG`` en orientación
transcripcional.

El análisis se aplicó únicamente a los loci previamente clasificados como
``ZFP28_CHIMERIC_COMPLETE``.

Crear el script de validación:

.. code-block:: bash

   nano scripts/03_validate_ZFP28_exon7.py

Pegar el siguiente código:

.. code-block:: python

   #!/usr/bin/env python3

   from pathlib import Path
   import subprocess
   import csv


   # ============================================================
   # RUTAS
   # ============================================================

   ROOT = Path(__file__).resolve().parent.parent
   PROJECT = ROOT.parent.parent

   SPECIES_ROOT = PROJECT / "SPECIES"
   RESULTS = ROOT / "results"
   INTERMEDIATE = ROOT / "intermediate"

   OUT = RESULTS / "ZFP28_exon7_splice_validation.tsv"


   # ============================================================
   # FUNCIONES
   # ============================================================

   def revcomp(seq):
       """
       Obtiene el complemento reverso de una secuencia de ADN.
       Se utiliza para expresar las bases en orientación transcripcional
       cuando el locus está localizado en la hebra negativa.
       """

       comp = str.maketrans(
           "ACGTNacgtn",
           "TGCANtgcan"
       )

       return seq.translate(comp)[::-1]


   def get_seq(fasta, scaffold, start, end):
       """
       Extrae una región genómica usando samtools faidx.

       Las coordenadas utilizadas son 1-based e inclusivas.
       """

       if start < 1:
           return ""

       fai = Path(str(fasta) + ".fai")

       if not fai.exists():

           subprocess.run(
               ["samtools", "faidx", str(fasta)],
               check=True,
               stdout=subprocess.DEVNULL
           )

       region = f"{scaffold}:{start}-{end}"

       p = subprocess.run(
           [
               "samtools",
               "faidx",
               str(fasta),
               region
           ],
           check=True,
           capture_output=True,
           text=True
       )

       lines = p.stdout.strip().splitlines()

       if len(lines) < 2:
           return ""

       return "".join(lines[1:]).upper()


   # ============================================================
   # RECORRER LOS RESULTADOS DE ZFP28
   # ============================================================

   rows_out = []

   for result_file in sorted(
       RESULTS.glob("ZFP28_signature_*.tsv")
   ):

       species = result_file.stem.replace(
           "ZFP28_signature_",
           ""
       )

       # --------------------------------------------------------
       # Seleccionar únicamente las arquitecturas completas
       # --------------------------------------------------------

       with open(result_file) as fh:

           reader = csv.DictReader(
               fh,
               delimiter="\t"
           )

           complete_rows = [
               r for r in reader
               if r["Status"] ==
               "ZFP28_CHIMERIC_COMPLETE"
           ]

       if not complete_rows:
           continue


       # --------------------------------------------------------
       # Localizar el genoma correspondiente
       # --------------------------------------------------------

       species_dir = SPECIES_ROOT / species

       genomes = list(
           species_dir.glob("*.fa")
       )

       if len(genomes) != 1:

           print(
               f"OMITIR {species}: "
               f"se esperaba exactamente un FASTA genómico"
           )

           continue

       genome = genomes[0]


       # --------------------------------------------------------
       # Abrir los resultados BLAST originales de GOLEM-1p
       # --------------------------------------------------------

       blast_file = (
           INTERMEDIATE /
           species /
           f"ZFP28_GOLEM_matches_{species}.tsv"
       )

       if not blast_file.exists():

           print(
               f"OMITIR {species}: "
               f"no se encontró el archivo BLAST de GOLEM"
           )

           continue


       blast_hits = []

       with open(blast_file) as fh:

           for line in fh:

               if not line.strip():
                   continue

               f = line.rstrip().split("\t")

               if len(f) != 12:
                   continue

               (
                   qseqid,
                   sseqid,
                   pident,
                   length,
                   qlen,
                   qstart,
                   qend,
                   sstart,
                   send,
                   evalue,
                   bitscore,
                   qcov
               ) = f

               sstart = int(sstart)
               send = int(send)

               blast_hits.append({

                   "qseqid": qseqid,
                   "scaffold": sseqid,

                   "pident": float(pident),
                   "length": int(length),

                   "qlen": int(qlen),
                   "qstart": int(qstart),
                   "qend": int(qend),

                   "sstart": sstart,
                   "send": send,

                   "start": min(sstart, send),
                   "end": max(sstart, send),

                   "strand":
                       "+" if sstart <= send else "-",

                   "qcov": float(qcov),
                   "bitscore": float(bitscore)
               })


       # ========================================================
       # VALIDAR CADA ARQUITECTURA COMPLETA
       # ========================================================

       for r in complete_rows:

           scaffold = r["Scaffold"]
           strand = r["Strand"]

           golem_start = int(
               r["GOLEM_start"]
           )

           golem_end = int(
               r["GOLEM_end"]
           )


           # ----------------------------------------------------
           # Recuperar exactamente el hit de GOLEM utilizado
           # por el detector de arquitectura
           # ----------------------------------------------------

           candidates = [

               h for h in blast_hits

               if h["scaffold"] == scaffold
               and h["strand"] == strand
               and h["start"] == golem_start
               and h["end"] == golem_end
           ]


           if not candidates:

               print(
                   f"ADVERTENCIA {species}: "
                   f"no fue posible recuperar el hit GOLEM "
                   f"{scaffold}:{golem_start}-{golem_end}"
               )

               continue


           hit = max(
               candidates,
               key=lambda x: x["bitscore"]
           )


           qlen = hit["qlen"]
           qstart = hit["qstart"]
           qend = hit["qend"]

           sstart = hit["sstart"]
           send = hit["send"]


           # ----------------------------------------------------
           # Reconstruir las coordenadas esperadas del exón 7
           #
           # El BLAST puede no comenzar exactamente en el
           # nucleótido 1 de la sonda, por lo que se corrigen
           # los extremos no alineados utilizando qstart/qend.
           # ----------------------------------------------------

           if strand == "+":

               exon7_start = (
                   sstart -
                   (qstart - 1)
               )

               exon7_end = (
                   send +
                   (qlen - qend)
               )


               # En strand positivo, el aceptor de splicing
               # se encuentra inmediatamente antes del inicio
               # del exón 7.

               genomic_acceptor = get_seq(
                   genome,
                   scaffold,
                   exon7_start - 2,
                   exon7_start - 1
               )

               transcript_acceptor = (
                   genomic_acceptor
               )


           else:

               # En strand negativo, qstart corresponde
               # al extremo genómico de coordenada mayor.

               exon7_end = (
                   sstart +
                   (qstart - 1)
               )

               exon7_start = (
                   send -
                   (qlen - qend)
               )


               # En orientación transcripcional, la región
               # inmediatamente anterior al exón 7 se encuentra
               # hacia coordenadas genómicas mayores.

               genomic_acceptor = get_seq(
                   genome,
                   scaffold,
                   exon7_end + 1,
                   exon7_end + 2
               )

               transcript_acceptor = revcomp(
                   genomic_acceptor
               )


           # ----------------------------------------------------
           # Clasificar el sitio aceptor
           # ----------------------------------------------------

           if transcript_acceptor == "AG":

               acceptor_status = (
                   "CANONICAL_AG"
               )

           else:

               acceptor_status = (
                   "NONCANONICAL"
               )


           # ----------------------------------------------------
           # Guardar resultados
           # ----------------------------------------------------

           rows_out.append({

               "Species":
                   species,

               "Genome":
                   genome.name,

               "Scaffold":
                   scaffold,

               "Strand":
                   strand,

               "Host_exons":
                   r["Exons_found"],

               "Exon7_start_predicted":
                   exon7_start,

               "Exon7_end_predicted":
                   exon7_end,

               "GOLEM_qstart":
                   qstart,

               "GOLEM_qend":
                   qend,

               "GOLEM_qcov":
                   hit["qcov"],

               "GOLEM_identity":
                   hit["pident"],

               "Acceptor_genomic_2bp":
                   genomic_acceptor,

               "Acceptor_transcript_2bp":
                   transcript_acceptor,

               "Acceptor_status":
                   acceptor_status
           })


   # ============================================================
   # ESCRIBIR LA TABLA FINAL
   # ============================================================

   header = [

       "Species",
       "Genome",
       "Scaffold",
       "Strand",

       "Host_exons",

       "Exon7_start_predicted",
       "Exon7_end_predicted",

       "GOLEM_qstart",
       "GOLEM_qend",

       "GOLEM_qcov",
       "GOLEM_identity",

       "Acceptor_genomic_2bp",
       "Acceptor_transcript_2bp",

       "Acceptor_status"
   ]


   with open(OUT, "w") as out:

       out.write(
           "\t".join(header) + "\n"
       )

       for r in rows_out:

           out.write(
               "\t".join(
                   str(r[x])
                   for x in header
               )
               + "\n"
           )


   print()

   print(
       f"Loci completos validados: "
       f"{len(rows_out)}"
   )

   print(
       f"Archivo de salida: {OUT}"
   )

* *Rhinolophus foetidus*

degradación considerable del extremo 5′ del componente derivado del TE.

Estos dos loci se conservaron como arquitecturas host completas con un
exón 7 degradado o incierto, pero no fueron incluidos entre los
positivos completos de alta confianza.


12. Integración de ZFP28 en el análisis final de dN/dS
======================================================

12.1. Objetivo de esta segunda etapa
------------------------------------

La detección de la arquitectura genómica descrita en las secciones
anteriores responde a una pregunta distinta de la reconstrucción de la
CDS utilizada para análisis de selección.

La primera etapa identificó loci con:

* los seis exones host de ZFP28;
* un elemento GOLEM-1p situado en el extremo biológico 3';
* orientación coherente;
* orden exónico coherente;
* y, cuando fue posible, un sitio aceptor canónico antes del exón 7
  derivado del TE.

Sin embargo, las sondas utilizadas para detectar la arquitectura no deben
interpretarse automáticamente como límites exactos de la CDS del
transcrito quimérico de referencia.

Por esta razón, la reconstrucción para dN/dS se realizó a partir del
transcrito quimérico experimental de referencia y no a partir del consenso
GOLEM-1p ni de los límites de los HSPs de BLAST.

15. Regla de fase en la unión HOST-TE
=====================================

En ZFP28, como en las otras arquitecturas utilizadas para selección, la
unión HOST-TE corta un codón.

La referencia tiene:

.. code-block:: text

   HOST length % 3 = 1
   TE length   % 3 = 2

Por lo tanto, el codón situado en la frontera está formado por:

.. code-block:: text

   1 nt HOST + 2 nt TE

Este codón mixto se conserva en la CDS quimérica completa.

Sin embargo, para análisis independientes de HOST y TE no se debe
asignar ese codón a ninguno de los dos componentes.

Por lo tanto:

.. code-block:: text

   HOST puro para selección = HOST[:-1]
   TE puro para selección   = TE[2:]

Esta regla evita atribuir un codón de origen mixto exclusivamente al host
o exclusivamente al TE.


16. Auditoría de los BLAST de arquitectura existentes
=====================================================

16.1. Razón de la auditoría
---------------------------

Los BLAST utilizados para detectar la arquitectura habían sido generados
con sondas completas de exones. BLAST es una alineación local y puede
recortar bases en los extremos de un HSP.

Por ejemplo, se observaron resultados como:

.. code-block:: text

   q=2-92/92
   q=10-580/580
   q=124-580/580

Estos valores no demuestran por sí solos que las bases no alineadas hayan
sido eliminadas biológicamente.

Por esta razón, los HSPs antiguos no se trataron como límites exactos de
exón.

El script de auditoría fue::

   ANALYSES/dNdS_FINAL/scripts/25_audit_ZFP28_existing_hits.py

La salida fue::

   ANALYSES/dNdS_FINAL/results/ZFP28_host_existing_hits_audit.tsv


16.2. Hallazgo crítico: hits parálogos
--------------------------------------

La auditoría reveló además que seleccionar únicamente el mejor hit por
scaffold y strand podía recuperar un paralogo fuera del locus ZFP28.

Por ejemplo, en especies de ``Molossus`` existían hits de exon 3 situados
varios megabases lejos de los otros exones del locus.

Por lo tanto, la reconstrucción final añadió una regla adicional:

**un hit exónico solo podía utilizarse si estaba físicamente dentro del
locus ZFP28 previamente identificado por el detector de arquitectura.**

Esta restricción es esencial y no debe eliminarse en futuras
reimplementaciones.


17. Reconstrucción final de ZFP28 en las 24 especies
====================================================

17.1. Principio de reconstrucción
---------------------------------

La reconstrucción final no volvió a ejecutar búsquedas genómicas
exploratorias.

Se reutilizaron:

* los 24 loci ``ZFP28_CHIMERIC_COMPLETE`` ya identificados;
* los BLAST de exones ya existentes;
* la tabla de validación del exón 7;
* los genomas originales.

El script final fue::

   ANALYSES/dNdS_FINAL/scripts/26_reconstruct_ZFP28_final.py

Su lógica fue:

#. leer cada uno de los 24 loci previamente identificados;
#. restringir los hits exónicos al scaffold, strand y locus correcto;
#. seleccionar el mejor ancla de cada exon dentro del locus;
#. usar ``qstart`` y ``qend`` solamente para extender el HSP hacia los
   límites esperados del exon;
#. extraer del genoma la secuencia literal resultante;
#. no corregir mutaciones, indels, stops o bases ambiguas;
#. tomar solo los últimos 220 nt del exon 1 en orientación
   transcripcional;
#. concatenar los exones 2-6;
#. recuperar los primeros 362 nt del exón 7 en orientación
   transcripcional;
#. concatenar HOST + TE;
#. traducir la secuencia;
#. registrar marco, inicio, stops y bases ambiguas.

IMPORTANTE
~~~~~~~~~~

El script no "repara" secuencias.

Si una especie posee una inserción, deleción, stop interno o sustitución,
esa diferencia debe permanecer en la secuencia reconstruida.

18. Corrección del criterio de QC
=================================

18.1. Problema detectado
------------------------

La primera versión del QC exigía que todas las especies tuvieran un stop
terminal exactamente en el mismo extremo homólogo definido por los 362 nt
TE de la referencia.

Ese criterio resultó demasiado estricto.

La ausencia de un stop terminal exactamente en el extremo homólogo de la
referencia no implica necesariamente una pérdida de capacidad codificante.
En otra especie, la ORF puede continuar más allá del extremo homólogo
analizado.

Por ejemplo, ``Eonycteris spelaea`` presentó:

.. code-block:: text

   ATG = YES
   chimera mod 3 = 0
   internal stops = 0
   ambiguous bases = 0
   terminal stop at reference endpoint = NO

La secuencia no debía excluirse únicamente por la ausencia de stop en ese
punto.


18.2. Criterios finales para inclusión en dN/dS
-----------------------------------------------

Una secuencia fue considerada ``PASS`` cuando cumplió:

.. code-block:: text

   chimera length % 3 = 0
   start codon = ATG
   internal stops = 0
   ambiguous bases = 0
   HOST phase = 1
   TE phase = 2
   exon7 acceptor = CANONICAL_AG

La presencia de un stop terminal exactamente en el extremo homólogo de la
referencia fue conservada como información descriptiva, pero dejó de ser
un criterio de exclusión.

Los casos con problemas codificantes independientes, por ejemplo stops
internos, fueron clasificados como ``FAIL`` incluso cuando además

21. Regla metodológica general aprendida durante este proyecto
==============================================================

La distinción siguiente debe conservarse en cualquier reproducción futura:

Arquitectura genómica
---------------------

Se utiliza para responder:

* ¿existe el locus?
* ¿están presentes los exones host?
* ¿existe el TE apropiado en el extremo esperado?
* ¿se conserva la orientación?
* ¿se conserva la estructura general?

Puede utilizar sondas exónicas y consensos TE.

Reconstrucción codificante
--------------------------

Se utiliza para responder:

* ¿qué nucleótidos pertenecen realmente a la CDS?
* ¿qué parte es host?
* ¿qué parte es TE?
* ¿se conserva la fase?
* ¿la secuencia es utilizable para análisis de selección?

Debe estar anclada al transcrito quimérico de referencia y a sus límites
codificantes reales.

**No se deben sustituir los límites de la CDS por coordenadas del consenso
TE ni por los extremos de un HSP local de BLAST.**

==================================================

#. No volver a descubrir ZFP28 desde cero. La arquitectura ya fue
   identificada y validada en 24 loci.

   biológicos exactos de exones.
